## Selected collaboration · Chemistry × Python

### [Molecular Rotation Automation](https://github.com/andrewyazura/rotate-molecules)

A small computational chemistry tool developed from a university chemistry problem I formulated: generate molecular structures by rotating part of a molecule around a **C–N glycosidic bond**.

The Python implementation was created by my former chemistry student **[Andrew Yazura](https://github.com/andrewyazura)**. The project generates **360 Gaussian input (`.gjf`) structures** and demonstrates how a chemistry problem can be translated into a computational workflow.

**My role:** chemistry problem definition and scientific context  
**Implementation:** Andrew Yazura · Python
